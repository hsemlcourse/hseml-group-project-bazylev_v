## 1. Введение и постановка задачи
* **Цель проекта:** Автоматизация классификации космических объектов на основе фотометрических снимков для ускорения обработки данных современных телескопов.
* **Задача:** Мультиклассовая классификация небесных тел на 3 категории: Звезды (`STAR`), Галактики (`GALAXY`) и Квазары (`QSO`).
* **Обоснование метрики качества:** Выбрана метрика F1-macro. В астрономии крайне важно одинаково хорошо распознавать как массовые объекты (галактики), так и редкие аномальные структуры (квазары). Традиционная метрика Accuracy здесь неприменима: при сильном дисбалансе классов модель может просто игнорировать редкие объекты, сохраняя высокий общий процент точности. F1-macro вычисляет F1-score для каждого класса независимо и усредняет их, жестко наказывая модель за провалы на редких классах.

## 2. Поиск и описание данных
* **Источник:** Sloan Digital Sky Survey (SDSS), сборка данных DR14.
* **Объем выборки:** 10,000 наблюдений, 18 исходных признаков.
* **Ключевые физические признаки:**
  * `u`, `g`, `r`, `i`, `z` — величины блеска объекта в 5 различных электромагнитных фильтрах (от ультрафиолета до инфракрасного диапазона).
  * `redshift` — красное смещение. Физический параметр, показывающий степень сдвига спектра объекта в красную сторону из-за эффекта Доплера (свидетельствует об удаленности объекта от Земли).
* **Технические признаки:** Идентификаторы съемки (`objid`, `run`, `camcol`, `field`, `plate` и др.), которые не несут физического смысла и описывают лишь параметры телескопа в момент захвата кадра.

## 3. Обработка и подготовка данных
* **Очистка данных:** Удалены полные дубликаты строк. Технические столбцы, способные вызвать дата-лик (data leakage) или переобучение модели на конкретные участки неба, полностью удалены из датасета.
* **Feature Engineering:** На основе пяти базовых фильтров созданы цветовые индексы: `u-g`, `g-r`, `r-i`, `i-z`. В астрофизике эти разности характеризуют распределение энергии в спектре и помогают точнее отделять тепловое излучение звезд от специфического свечения галактик.
* **Разбиение данных:** Датасет разделен на три выборки: обучающую (train — 60%), валидационную (val — 20%) и тестовую (test — 20%). При разбиении использовалась стратификация (`stratify=y`), гарантирующая одинаковое соотношение классов во всех трех частях.
* **Воспроизводимость:** Для всех процедур разделения данных жестко зафиксирован параметр `random_state=42`. Перед подачей в линейные модели данные проходят стандартизацию через `StandardScaler`.

## 4. Baseline-модель
В роли базового решения выступила многоклассовая **Логистическая регрессия (Logistic Regression)** со стандартными параметрами регуляризации.
* **Результат на валидации (F1-macro):** 0.9754
* **Вывод:** Высокое качество бейзлайна объясняется линейной разделимостью классов по признаку `redshift`. Звезды имеют околонулевое смещение, галактики — небольшое, а квазары — крайне высокое. Однако для минимизации пограничных ошибок требуется более гибкий нелинейный алгоритм.

## 5. Эксперименты
Все эксперименты оценивались на отложенной валидационной выборке. Поиск оптимальных гиперпараметров для бустинга проводился с помощью фреймворка `Optuna` (20 итераций).

| Модель | Гипотеза | Как проверялось | Результат (F1-macro) |
| :--- | :--- | :--- | :--- |
| **Baseline (LogReg)** | Классы линейно разделимы по спектрам | Стандартная регрессия на scaled-фичах | 0.9754 |
| **K-Nearest Neighbors** | Объекты одного типа образуют плотные группы | KNN с $n\_neighbors=5$ | 0.9490 |
| **Random Forest** | Комбинация случайных деревьев снизит оверфит | Ансамбль из 100 деревьев, из коробки | 0.9855 |
| **XGBoost** | Градиентный бустинг точнее настроит веса на стыках классов | Оптимизация гиперпараметров через Optuna | 0.9901 |
| **Stacking Classifier** | Объединение сильных сторон бустинга и случайного леса | Стек из XGBoost и RF под мета-цензором LogReg | 0.9915 |

## 6. Финальная модель + интерпретируемость результатов
* **Выбор модели:** Финальным решением стал **Stacking Classifier** - тандем XGBoost и RandomForest с мета-классификатором Logistic Regression. Он позволил выжать максимум из структуры данных, достигнув F1-macro = 0.9915.
* **Интерпретируемость:** Анализ важности признаков (Feature Importance) базовых моделей подтвердил физические законы космологии. Самым весомым признаком с огромным отрывом является `redshift` (поскольку квазары физически находятся намного дальше любых звезд нашей Галактики). На втором и третьем местах по значимости закрепились сгенерированные признаки цветовых индексов `g-r` и `u-g`, помогающие разделять звезды и галактики со схожим смещением.

## 7. Деплой
В рамках финального этапа разработан рабочий микросервис:
1. **FastAPI:** Развернут REST API (файл `src/app.py`), принимающий JSON с характеристиками космического тела, рассчитывающий на лету цветовые индексы, масштабирующий признаки и возвращающий предсказанный класс вместе с вероятностями.
2. **Streamlit:** Создан пользовательский веб-интерфейс (файл `src/interface.py`) со слайдерами и полями ввода для удобной отправки запросов к API.
